### Why Timeline Block?

**Timeline Block** is your solution for creating visually stunning and fully customizable timelines in WordPress. With 2 free unique themes (and 8 more in the Premium version), each supporting both horizontal and vertical layouts, the plugin offers real flexibility for presenting stories, projects, milestones, or events.

Designed with user-friendliness in mind, Timeline Block lets you effortlessly add, edit, and style your timeline directly in the WordPress editor. Customize colors, fonts, icons, and more to align perfectly with your brand or website design. Whether you're creating a project roadmap, a personal story, or a historical timeline, the plugin adapts to your needs with precision.

### Free Features

- **Two Free Themes:** Customize the default themes to match your style and preferences.
- **Timeline Type:** Easily switch between horizontal and vertical layouts in the default theme.
- **Start Index:** Set the starting position (left or right) for both horizontal and vertical timelines.
- **Display Item:** Choose how many items to display in the horizontal timeline for a tailored view.
- **HTML in Timeline Titles:** Add custom HTML to enhance your timeline titles.

### Pro Version

Upgrade to [**Timeline Block Pro**](https://bplugins.com/products/timeline-block/pricing/) for more themes and design control.

- **Shortcode API:** A powerful shortcode feature that lets you use the timeline anywhere on your site.
- **Eight Extra Themes:** Access eight more professionally designed themes, some supporting both horizontal and vertical layouts.
- **Classic Editor for Descriptions:** Edit timeline descriptions with the integrated classic editor and advanced formatting options.
- **Customizable Icons:** Add unique icons to your timeline items and style them for a polished, professional look.
- **Enhanced Customization Options:** Fine-tune every aspect of your timeline for ultimate design control.
- **Animation:** Add animation to your timeline items.

### How to Use

1. Install and activate the **Timeline Block** plugin.
2. Add the **Timeline Block** block from the block category called "Widgets" in the Gutenberg editor.
3. Change the block settings from the right-side settings sidebar.
4. Publish – your timeline is live!

### Use Cases

- **Project Roadmaps:** Present phases and milestones in a clear visual sequence.
- **Company History:** Tell your brand's story year by year.
- **Personal Stories & Portfolios:** Walk visitors through your journey and achievements.
- **Events:** Lay out schedules and historical timelines in an engaging format.

== Installation ==

**From your WordPress dashboard (recommended):**

1. Go to **Plugins → Add New**.
2. Search for **"Timeline Block"**.
3. Click **Install Now**, then **Activate**.
4. Add the **Timeline Block** block to any post or page in the Gutenberg editor.

**Manual installation:**

1. Download the **Timeline Block** plugin (*.zip file*).
2. In your admin area, go to **Plugins → Add New**, click **Upload Plugin**, choose the `timeline-block.zip` file, and click **Install Now**.
3. Or upload the plugin folder to the `/wp-content/plugins/` directory and activate it through the **Plugins** menu in WordPress.

== Frequently Asked Questions ==

= Is Timeline Block free? =

Yes, Timeline Block is a free Gutenberg block plugin. A Premium version with additional themes and features is also available.

= Does it work with any WordPress theme? =

Yes, it works with any standard WordPress theme.

= Can I create both horizontal and vertical timelines? =

Yes. The default theme supports both horizontal and vertical layouts, and you can switch between them from the block settings.

= How many themes are included? =

The free version includes 2 unique themes. The Premium version adds 8 more professionally designed themes, some supporting both horizontal and vertical layouts.

= Can I change the block settings? =

Yes, you can change the block settings from the Gutenberg block editor's right sidebar, including layout type, start index, and the number of visible items.

= Can I use the timeline outside the block editor? =

Yes. The Pro version includes a powerful Shortcode API that lets you place the timeline anywhere on your site.

= How many times can I reuse the block? =

You can use the block an unlimited number of times across your site.

= Where can I get support? =

You can post your questions on the [support forum here](https://wordpress.org/support/plugin/timeline-block-block/).

= Where do I report security bugs found in this plugin? =

Please report security bugs found in the source code of the Timeline Block plugin through the [Patchstack Vulnerability Disclosure Program](https://patchstack.com/database/vdp/9e5fb645-ef15-4628-91b6-de61c8ef0e78). The Patchstack team will assist you with verification, CVE assignment, and notify the developers of this plugin.
